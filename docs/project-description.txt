This project is for analyzing team data from various playthroughs of Pokemon games.

I'm building it to identify common patterns and tendencies in general species and type choice across games, including whether or not I've picked specific species whenever it's been possible.

For example, in the Generation 4 games(Diamond, Pearl, Platinum, Brilliant Diamond, Shining Pearl, and Legends Arceus), I'd want to see whether or not I had a certain pokemon, like Torterra, in each game. 

Features I want to include:
- Dashboard showing different data points such as how many games have been played, how many times a particular game has been played, and the most common types across playthroughs. 
- Text-search to see specific species
- Filtering by pokemon type, game, the year I played it, and the generation(Gen 1, 2, 3, etc)
- Sprites/models of each pokemon in each entry varying by the playthrough being recorded
- Login: user creates an account with a password and has multi-factor authentication required through either code sent to email or generated by auth app.
